10 Useful HTML Tags

  • div - used for grouping content
  • span - inline container
  • section - separates sections
  • header - top part of page
  • footer - bottom part of page
  • nav - navigation links
  • a - hyperlinks
  • img - images
  • form - forms and input
  • button - clickable button

Important SEO Tags

  • title tag helps search engines know page title
  • meta description gives short page summary
  • viewport tag helps mobile responsiveness
  • h1 tag tells the main heading of page
  • alt text improves accessibility and SEO
  • semantic tags like section and nav improve structure

Different Font Sizes

  • px is useful when exact size is needed
  • pt is mostly used for printing documents
  • em changes based on parent size
  • rem uses root font size
  • percentage is useful for responsive text
  • vw changes based on screen width

CSS Positioning

static position is default
relative moves from original place
absolute is inside parent
fixed stays on screen

Static is used for normal flow.

Relative helps move elements slightly.

Absolute is useful for overlays or labels.

Fixed is useful for sticky buttons or menus.
